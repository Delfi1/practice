### Case 1 — Поиск нетипичного поведения заявок на закупку

По журналу событий закупок нужно определить обычное поведение, задать понятные
критерии аномальности и найти подозрительные экземпляры: пропуск обязательных
этапов, неверные роли исполнителей, аномальные длительности и суммы, избыточные
возвраты на доработку. Итог — `anomalies.csv` с объяснением каждого отклонения.

- Ноутбук: `case1.ipynb`
- Данные: `Case1/students.csv`
- Результат: `ResultCase1/anomalies.csv`

### Case 2 — Восстановление процесса по журналу событий

Без исходной схемы процесса нужно восстановить его модель по завершённым
историям заявок: активности и их порядок, переходы, развилки, возвраты,
обязательные и опциональные этапы, частоты вариантов. Итог — схема (Mermaid),
отчёт, таблица вариантов и CSV переходов.

- Ноутбук: `case2.ipynb`
- Данные: `Case2/students.csv`
- Результат: `ResultCase2/variants.csv`, `ResultCase2/student_transitions.csv`
